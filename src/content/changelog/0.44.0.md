## Features

- **Settings that fit the host panel:** a compact section dropdown replaces the old tabs without adding another sidebar. Searchable Projects and Secrets managers provide explicit Save/Cancel editing, scoped secrets, and confirmed deletion. (#587)
- **Explicit Codex computer-use control:** the new Agent setting defaults to off for new and existing installations. Turn it on to inherit your local Codex computer-use configuration. (#586)
- **Inline content from peer plugins:** compatible plugins can contribute cards, images, and isolated interactive documents directly inside assistant messages, with safe fallback content when a provider is unavailable. (#588)

## Upgrade notes

- Computer-use changes apply to newly started or restarted Codex sessions. Running and warm sessions retain their current access until restarted. After active work finishes, use **Reload plugin (safe)** to apply the setting across sessions.
- Disabling Codex computer use may also disable its shared browser REPL. Agent Threads' own browser tools remain available. This setting does not replace OS permissions or restrict every third-party automation tool.
- Existing settings and stored projects/secrets are preserved. Mobile keeps its pairing and relay settings screen.
- Inline peer-plugin content requires a compatible provider; streaming and mobile relay views use inert fallbacks.

Update through **Settings → BRAT → Update all beta plugins**.
