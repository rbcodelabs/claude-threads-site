## Features

- **OAuth client secrets for MCP servers:** connect providers that require a confidential client. Enter the secret in Settings → MCP → Add MCP server → OAuth → Advanced, or let an agent reference a secret saved with `request_secret`. Secrets stay in the OS keychain. Credentials issued during Dynamic Client Registration are retained automatically. (#585)
- **Peer-orchestrator thread controls:** compatible peer plugins can archive a thread or mark it reviewed through the public API, with protected-target confirmations, persistence checks, and updates to the list and board. (#590)

## Fixes and improvements

- **Skills Manager navigation:** expanding or collapsing a GitHub source with its chevron keeps you on the skills list. Clicking the source row still opens its details. The disclosure has accessible state and a 44×44 target in narrow panes. (#592)
- **OAuth disconnect:** revocation selects the provider's supported client-authentication method, including HTTP Basic, before clearing local credentials.
- Updated the public OAuth and Skills Manager documentation, and recorded the Threads Orchestrator successor identity and migration obligations. (#591; claude-threads-site#107)
