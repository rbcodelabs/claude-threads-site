## Features
- Peer-registered slash commands can now supply argument-completion suggestions in the composer's existing dropdown (the same UI already used for `/model`), via an optional `SlashCommandHandler.argCompletions` field. Fully backward compatible — an older peer or an older host build simply ignores the field. (#627)
