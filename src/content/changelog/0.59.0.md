## Features
- **Inline host-exec approval (#704)** — `host_exec` approvals now appear as an inline permission card in the thread (Allow once / Deny, never "Always allow") instead of a modal. Approval prompts are queued behind any other pending prompt so only one is ever shown per thread.

## Bug Fixes
- **Loops stay in one thread (#694)** — when a loop's thread is closed, the loop is retargeted onto a single replacement thread instead of spawning a new one each cycle.
- **Skills tree row sizes (#703)** — equal tree row heights and toggle size in the narrow layout; also de-flakes the OAuth focus-ring and keyboard-reachability screenshot specs.

## Improvements
- Dependency bumps: hono 4.13.12 (#671), undici 7.30.0 (#661), adm-zip 0.6.1 (#659).

## Notes
- Not included: #701 (remove enter_vm/vm_exec/exit_vm tools) and #679 (idle-stop VMs) remain open.
