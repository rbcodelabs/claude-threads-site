## Features

- **Agent Browser: sign-in handoff for OAuth-style logins** (#631) — Sites that gate access behind a popup login (Google, GitHub, SSO) were previously permanently unusable by the agent, since Claude can't see or drive a popup window. The embedded browser preview now shows a "This page wants you to sign in — Take control?" banner with a 30-second countdown; accepting opens a temporary page in the same pane where your own clicks and typing go directly to the login flow, completely separate from Claude's session. Click **Return control** (or close the temporary page) when you're done, and Claude picks up wherever the sign-in left things. Implements [ADR-0014](docs/adr/0014-agent-browser-login-handoff.md), built on top of Geode's window.open()/opener bridge.

## Bug Fixes

- **`request_secret` now updates the live thread immediately** (#629) — Previously, a secret saved mid-conversation via `request_secret` sat in the keychain invisible to the very thread that asked for it until some unrelated event happened to restart its session. The thread that requested the secret now restarts its own session on the next turn (conversation history preserved via resume), so the new credential is usable right away instead of only in a future session.

## Improvements

- **Google Docs MCP connectivity probe** (#533) — Adds a standalone, dependency-free script (`scripts/probe-google-docs-mcp.mjs`) and guide (`docs/google-docs-mcp-pilot.md`) for validating the Google Docs Sync OAuth connection against Google's hosted MCP server on a corporate machine. No runtime plugin behavior changes — this is a diagnostic tool for reproducing and troubleshooting the MCP pilot, not a new integration.
- **Dependency maintenance** — Routine dependency bumps in the `/screenshots` (Remotion, PostCSS) and `/relay` (sharp, Wrangler) subpackages (#609, #604, #606) to pick up upstream fixes. No functional changes to the plugin itself.
