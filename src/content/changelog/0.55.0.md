## Features

- **Large-file Google Drive upload and download for threads (#657).** Enabling Google Drive now also gives each thread a local `google-drive-files` MCP server with `upload_local_file` (resumable 8 MiB chunks, resumes after a dropped connection or 5xx, stored as-is with no Docs/Sheets conversion) and `download_to_local_file` (streams to disk, refuses to overwrite unless asked, verifies size; Docs/Slides export to PDF, Sheets to XLSX, Drawings to PNG). This removes the roughly 10 MiB cap of the inline connector tools.
  - Security hardening: file paths are confined to the thread's working directory and the vault; symlink escapes and `.obsidian` / `.git` are refused; the server uses the same capability token and revocation as the other Google servers (bogus or Docs-only tokens get 401, browser origins 403, reconnecting or disabling Drive revokes); chunk uploads never carry the bearer token and errors do not leak it.
- **Manage skill sources from the Skills Manager (#663).** The "+" menu gains "GitHub repo..." and "Local folder source..." entries, new sources are expanded and preloaded after adding, local sources get a "Remove source" control, and Settings > Skills now points to the Skills Manager.

## Bug Fixes

- **Browser login handoff (#650).** Fixed the pane snapping back to the agent mid-login, typed text not landing, clicks being eaten by an image drag, and hover-driven widgets ignoring the first click. "Take over" is now always available, not only for popup logins.

## Improvements

- Dependency updates: vitest / @vitest/mocker in /relay (#633) and ws / @remotion/cli in /screenshots (#607).
- Screenshot test harness fixes: skills manager harness mock and regenerated agent-browser baselines for the always-available Take over button (#667).

## Notes

- Uploads into Drive folders the app did not create may be rejected by Google because of the `drive.file` scope; this is documented in the README.
