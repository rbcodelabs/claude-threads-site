## Features
- **Zero-setup sandbox** (#648) — Agent Threads now manages the container runtime and a published base image, with one-click setup.
- **Claude harness inside the sandbox VM** (#644) — a Claude thread's CLI process can run in its sandbox container (Claude only).
- **Browser sign-in handoff** (#642) — a browser session card in chat, with in-chat sign-in handoff.
- **Expired Claude sign-in** (#639) — detected, retried automatically, and offers an in-thread login.

## Bug Fixes
- **`browser_read_text` on oversized pages** (#643) — no longer returns empty; new `browser_save_page` writes large pages to a file.
- **Scheduler overlap** (#582) — a cycle is skipped when the previous run is still in flight.
- **Mobile** (#641) — code blocks and prose stay inside the thread view.
