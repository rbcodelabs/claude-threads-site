## What's New in v0.28.0

### Features

- **Scheduled Work dashboard** — Settings now has a dedicated Scheduled tab with a durable **Next up** view, relative countdowns and exact timestamps, recurring versus thread-specific grouping, active-hours and gate details, recent run history, pause/resume/delete controls, **Open last run**, and **Create with Claude**. Gated jobs correctly show **Next check**, while overdue work is labeled **Overdue — catching up**. ([#447](https://github.com/rbcodelabs/obsidian-claude-threads/pull/447))

### Bug Fixes

- **Long schedules no longer overflow native timers** — intervals such as 30 days now use bounded heartbeat timers instead of overflowing JavaScript's signed 32-bit timeout ceiling and firing in a tight loop. ([#447](https://github.com/rbcodelabs/obsidian-claude-threads/pull/447))
- **Scheduled occurrences are claimed safely** — overlapping plugin generations serialize claims, re-authorize immediately before dispatch, and finalize against fresh persisted state. This prevents duplicate dispatches and prevents an in-flight run from resurrecting a schedule that was disabled. ([#447](https://github.com/rbcodelabs/obsidian-claude-threads/pull/447))
- **Calendar schedules retain durable behavior** — daily and weekly wake signals use pinned `node-cron` calendar handling while persisted `nextRun` remains authoritative for restart catch-up, gates, active hours, loops, and one-shot wakeups. ([#447](https://github.com/rbcodelabs/obsidian-claude-threads/pull/447))

### Improvements

- **Stable release screenshot gates** — npm and pnpm now resolve the same Playwright renderer version, and timing-sensitive footer/design-artifact tests wait for deterministic final UI state. ([#448](https://github.com/rbcodelabs/obsidian-claude-threads/pull/448))
- **Release metadata** — plugin, package, README badge, and Obsidian compatibility map are synchronized at `0.28.0`. ([#449](https://github.com/rbcodelabs/obsidian-claude-threads/pull/449))
- Public Scheduled Work documentation is live at [threads.rbcodelabs.com](https://threads.rbcodelabs.com/docs/automation/scheduled-tasks/). ([docs #45](https://github.com/rbcodelabs/claude-threads-site/pull/45))

### Notes

- Existing scheduled items remain compatible and acquire internal durability metadata lazily; no manual migration is required.
- Manual schedule editing, **Run now**, and future calendar projection are not part of this release. Create or revise scheduled work conversationally through Claude.
