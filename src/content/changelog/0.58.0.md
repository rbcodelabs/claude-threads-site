## Features
- **Quick connect presets for OAuth MCP servers.** Settings → MCP now offers one-click presets for Atlassian, v0, Linear, Notion, Vercel, Sentry and Asana, so you no longer have to look up each server's URL and OAuth settings (#673).
- **Public API for presets.** `mcp.listPresets` and `mcp.registerPreset` are available to other plugins, with capability strings for feature detection (#673).
- **Dispatch from Geode's quick switcher.** A "Dispatch new conversation" row in the Cmd/Ctrl+O quick switcher creates and opens a new thread from the text you typed. Geode desktop only; it is a silent no-op on Obsidian (#678).

## Improvements
- Tool permission prompts now show a readable summary with labeled fields in a collapsible "Details" section instead of raw, truncated JSON, across the thread view, dashboard, kanban and mobile (#675).

## Notes
- Dynamic client registration for the Atlassian, Sentry, Notion and Vercel presets has not yet been confirmed by a live connect. If a preset fails to register, please report it.
