## Features
- **Agent browser: visible cursor and focus ring (#674).** Frames of Claude's browser session now draw an agent cursor (with a click ripple) where it last clicked or typed, and a focus ring around the field it is typing into, so you can follow what it is doing. The marks are invisible to the agent's snapshots and never change page layout.
- **Live chat card (#674).** The inline browser card in chat now shows live frames while Claude is acting (and settles to the final screenshot when the session ends), mirroring the Agent Browser pane.
- **`browser_screenshot` save-to-path (#674).** Pass `save` (and optionally `filename`) to also write the PNG to a temp file and get its path and size back alongside the inline image.

## Fixes
- Unit test for sandbox external-root mounts no longer fails on Linux CI (#676, test-only).
