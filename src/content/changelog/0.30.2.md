## What's New in v0.30.2

### Bug Fixes

- **Kanban Project grouping now reconciles matching repositories correctly.** Unassigned threads whose origin repository or effective working-directory root matches a configured Project now join that Project's folder swimlane and Project column, preventing duplicate same-project groups. Explicit Project assignments remain authoritative, and legacy worktree, unknown-directory, and same-name repository fallbacks remain distinct and deterministic. ([#478](https://github.com/rbcodelabs/obsidian-claude-threads/pull/478))

### Documentation

- Updated the plugin README and [public Kanban documentation](https://threads.rbcodelabs.com/docs/views/kanban-board/) to explain Project reconciliation behavior.

### Notes

- No configuration changes or migrations are required.
- Release artifacts include `main.js`, `styles.css`, `manifest.json`, and `versions.json`.
