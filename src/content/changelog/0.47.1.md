Patch release with two bug fixes.

## Bug Fixes

- **Image attachments no longer save as empty files under Geode** (#612). Since about Sep 15, every image written under Geode (pasted screenshots and images from tool results or the model) was saved as a 0-byte file and showed as a broken image in the transcript. The plugin was passing base64 text to Geode's binary-write bridge, which expects an ArrayBuffer. Images are now decoded before the write. If a host reports a written size that doesn't match the image (including 0 bytes), the plugin falls back to the next write method instead of keeping the empty file. Files that were already saved empty are not recovered by this release.
- **Notice-row icons show up again, and notice rows are left-aligned** (#611). Background-task completion notices showed a tiny dot where the check or x icon should be. Seven built-in Lucide icons (`send`, `square`, `wrench`, `play`, `check-circle`, `alert-circle`, `brain-circuit`) were being overridden with copies that drew at 24% scale, so the fix also applies everywhere else those icons appear. Notice rows are now left-aligned, and their status icon lines up with the icons on the tool rows around them.

## Notes

- To update: Settings → BRAT → Update all beta plugins.
