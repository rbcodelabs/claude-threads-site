## What's New in v0.50.0

### Features

- **Chief of Staff first-run onboarding** — new installs now get a guided setup path instead of a static welcome screen. On first launch, Agent Threads starts a **Chief of Staff** thread that walks you through configuring a personal-assistant skill pack over your vault: project, people, and open-loop tracking, daily briefs, weekly reviews, and autonomy that grows with your trust over time. If the guided setup can't start (offline, or no supported agent CLI installed yet), you'll see the familiar static getting-started guide instead. You can also launch it anytime via **Set up Chief of Staff** from the command palette, and turn the first-run offer off entirely in Settings → General.

### Bug Fixes

- **Scheduler:** fixed a bug where weekly schedules tied to specific weekdays could silently skip days instead of firing on every scheduled occurrence.
- **Security:** clicking **Allow** once on a permission prompt no longer silently writes a permanent rule to your settings — a one-time approval now stays one-time, matching what the button says. (Note: if you also run the plain `claude` CLI against the same vault, approvals made inside the plugin no longer carry over to that separate CLI session — each now tracks its own approvals as intended.)

### Improvements

- **Time-aware agents** — every turn now tells Claude and Codex the current local date, time, and time zone, so agents reason correctly about "today," deadlines, and scheduling instead of relying on stale training-time assumptions.

### Notes

- No migration steps required. Existing installs are unaffected by the first-run onboarding change (it only applies to brand-new installs) and can opt into it anytime via the command palette.
