Changes the default in-process summarization model to `gemma-2-2b-it-q4f16_1-MLC` (Gemma 2 2B). Better instruction-following than Llama 3.2 1B at a similar download size (~1.5 GB).

Existing installs: update the **In-process model** field in Settings to `gemma-2-2b-it-q4f16_1-MLC` to pick up the new default, or enter any other model ID from [webllm.mlc.ai](https://webllm.mlc.ai).
