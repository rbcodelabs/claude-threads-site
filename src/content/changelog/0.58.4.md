## Features
- **Per-thread container/host run mode** (#698).
- **Private skill-source repos** (#700) via Geode's GitHub connection.
- **Auto-update GitHub skill sources** (#696) in the background.
- **New Project from the dispatch selector** (#697), with a folder picker for the working directory.

## Bug Fixes
- **MCP OAuth** (#705) — `offline_access` is requested by default, with a clear re-authorize error.
- **Prompts** (#702) — permission and question prompts are serialized per thread.
- **Sandbox images** (#706) — detects images without `gh`, shows the image version, and warns about a stale image at VM start.
