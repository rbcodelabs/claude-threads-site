## Sandbox VMs (opt-in)

Claude and Codex threads can now run explicit coding commands in a disposable Linux VM with `enter_vm`, `vm_exec`, and `exit_vm`. The VMs use Apple's `container` runtime on Apple-silicon Macs running macOS 26 or later. The feature is unavailable on mobile.

- Only the selected working directory is mounted (read-write at `/work`). No other host directories are exposed.
- The agent itself stays on the host. Only commands sent through `vm_exec` run in Linux.
- Timeouts are enforced inside the guest, so a stuck command can't hang the host CLI.
- Setup: `brew install container && container system start && container build --tag claude-threads-coding:1 sandbox/`. See [docs/sandbox-vms.md](https://github.com/rbcodelabs/agent-threads/blob/v0.46.0/docs/sandbox-vms.md).
