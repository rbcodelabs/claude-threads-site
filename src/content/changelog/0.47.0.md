## Features

- **Switch harnesses within an existing thread** ([#596](https://github.com/rbcodelabs/agent-threads/pull/596)) — Move an idle thread between Claude and Codex from the composer footer menu (**Harness**) without forking or replaying the transcript. The thread and its history stay in place; the target harness starts a fresh native session and receives one bounded handoff summary. Threads with active work, queued input, pending approvals/plans/questions, or background agents must settle first.
- **Inline plan rejection feedback** ([#595](https://github.com/rbcodelabs/agent-threads/pull/595)) — **Reject** on a Plan Mode card now opens an inline "Why are you rejecting this plan?" field while keeping the proposed plan visible. Submit with **Cmd/Ctrl+Enter** to send your reason as the next Plan-mode message; **Escape** or **Cancel** returns to the card. An empty reason keeps the previous generic revision prompt, and the agent stays in Plan mode either way.

## Improvements

- **Claude Agent SDK 0.3.282** ([#603](https://github.com/rbcodelabs/agent-threads/pull/603)) — Upgraded from 0.3.251. The context usage bar now excludes SDK "deferred" rows (tool schemas outside the context window) from usage math, while still listing them in the category breakdown.
