## What's New in v0.28.3

### Features

- **Promote a sent message to a goal** — right-click the latest sent, non-empty message and choose **Set as goal** when you realize a request should become durable goal context. The goal is saved before kickoff and works with both Claude and Codex while preserving conversation continuity. ([#455](https://github.com/rbcodelabs/obsidian-claude-threads/pull/455))

### Reliability

- Goal replacement and clearing now refresh authoritative session context only after active turns and permission, tool, or background-work callbacks settle. Rapid replacements are last-write-wins, and failed persistence restores the last durable goal without stranding queued messages. ([#455](https://github.com/rbcodelabs/obsidian-claude-threads/pull/455))

### Documentation

- Updated the README and public Goals guide with the retroactive workflow, eligibility rules, and session-refresh behavior. ([docs #47](https://github.com/rbcodelabs/claude-threads-site/pull/47))
- Updated plugin metadata, `versions.json`, and the README badge for v0.28.3. ([#456](https://github.com/rbcodelabs/obsidian-claude-threads/pull/456))

### Notes

- No migration or configuration changes are required.
- Update through BRAT to install the patch.
