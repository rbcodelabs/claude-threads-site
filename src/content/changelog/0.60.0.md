## Features
- **Agent browser devtools (#716)**: new `browser_console` and `browser_network` tools let agents read buffered console output and the requests a page made (read-only, no permission prompt, page-authored data returned as untrusted content). New `browser_eval` evaluates JavaScript in the page; it is off by default behind `enableAgentBrowserEval` and every call needs explicit approval.
- **Visible artifact storage (#718)**: artifacts live under a configurable root with per-plugin namespaces.

## Bug Fixes
- **Agent browser settings always visible (#720)**: the session cap and private-network settings now always show.
- **Sandbox cleanup (#717)**: sandbox containers are torn down on thread delete even without a cached manager; orphans are swept at startup.
- **Inline document frame (#719)**: background is now transparent.

## Improvements
- **Cross-project spawns need approval (#715)**: `threads_create` spawns across projects now require approval.
- **Docs (#708)**: standing guidance moved into CLAUDE.md; paths updated for the agent-threads rename.
